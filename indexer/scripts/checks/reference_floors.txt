# What a number of the graph may not fall under (docs/indexer/method.md §4.4, indexer/scripts/judgment/scorecard.py).
#
# One per line: `repo.metric :: floor :: note`, a percent. The floor is the value measured on `main`, rounded down to a hundredth;
# the graph is deterministic, so a number under its floor is a change of the graph, never noise. A line that starts with `#`
# is a comment. `typed-share` is the percent of a repo's CALLS that a type decided, for every language; `keyed`,
# `typed-precision`, `recall` and `typed-recall` are measured against TypeScript's checker (`checks/ts_checker.js`), for the TS
# repos of the micro set; `scope-agreement` is the percent of a Python repo's files whose scopes and names the scope index classifies as
# CPython's `symtable` does (`checks/python_scopes.py`). The scorecard runs in the `micro` job of every pull request that touches the indexer.
#
# A floor is lowered by editing its line in the diff of the change that lowers it, under the `graph-change` label; it is
# raised when a change improves the number (the scorecard prints the headroom). A new repo or number gets a line:
# `scorecard.py RUN_DIR --rows DIR --write-floors` prints them.
